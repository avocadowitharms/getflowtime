## Summary

The original idea for Flowtime looked a lot like every other productivity app.

Users would create an account, log in, synchronize their data, and access it from multiple devices.

At least, that was the plan.

The more I worked on the app, the more I questioned whether any of that was actually necessary.

Every modern productivity tool seems to start with friction.

Before users can solve the problem they came for, they're asked to create an account, verify an email address, choose a workspace name, configure settings, and sometimes even invite team members.

For a tool whose primary purpose is measuring time, that feels backwards.

## I Just Want to Start Tracking My Work

When I sit down to work, I don't want another account.

I don't want another password.

I don't want another subscription notification.

I just want to start tracking my work.

So I removed account creation entirely.

## What Changed

The result was surprisingly freeing.

Flowtime became faster to launch, easier to understand, and easier to trust.

The experience changed from:

Create account -> Configure workspace -> Start timer

to:

Open app -> Start timer

That sounds like a small difference, but it fundamentally changes how the software feels.

## Simpler on Purpose

Productivity tools often become more powerful over time.

Very few become simpler.

I think there is still value in software that does one thing well and gets out of the way.

Flowtime was built around that idea.
